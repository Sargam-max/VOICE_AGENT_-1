Google OAuth 2.0 Setup Guide

To connect your personal Gmail and Calendar, create free OAuth credentials in Google Cloud Console and paste them into your .env file (or Railway Variables).

1. Open Google Cloud Console:
Go to console.cloud.google.com/apis/credentials and select or create a project.
2. Enable the Gmail API:
In APIs & Services > Library, search for Gmail API and click Enable.
3. Create OAuth Client ID:
Go to Credentials > Create Credentials > OAuth client ID > Application type: Web application.
4. Add Authorized Redirect URI:
5. Paste Keys into .env (or Railway Variables):
GOOGLE_CLIENT_ID=your_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_secret
